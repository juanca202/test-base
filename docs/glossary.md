# Glosario

Términos de dominio del proyecto. Las definiciones funcionales de alto nivel viven en [SRS-001, sección 1.3](specs/changes/requirements/SRS-001-portal-procesos-baw/README.md); aquí se recogen los términos técnicos que aparecen en la documentación técnica y en las tareas de implementación.

**Fecha de creación:** 2026-09-11
**Última actualización:** 2026-09-11

## Términos

| Término                           | Definición                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **BAW**                           | IBM Business Automation Workflow. El motor de procesos existente cuya API REST consume el portal. Es la única fuente de datos: el portal no tiene backend ni almacenamiento propio.                                                                                                                                                              |
| **BPD**                           | _Business Process Definition_. La definición de un proceso en BAW; el «tipo» del que se crean instancias. Su representación gráfica es el diagrama que muestra «Rendimiento del proceso» ([MD-10](architecture/portal-procesos-baw/models/MD-10-diagrama-proceso-estado.md)).                                                                    |
| **BPMCSRFToken**                  | Cabecera HTTP que BAW exige en toda petición para protegerse de CSRF. Su valor es el `csrf_token` devuelto por el login ([MD-01](architecture/portal-procesos-baw/models/MD-01-sesion-credenciales.md)). **No es la credencial de autenticación**: esa es la cookie LTPA.                                                                        |
| **Coach**                         | Formulario de interacción humana definido dentro de BAW para una tarea. BAW lo renderiza por sí mismo; el portal lo sustituye por un formulario propio construido dinámicamente ([MD-06](architecture/portal-procesos-baw/models/MD-06-campo-formulario-dinamico.md)).                                                                           |
| **Container / acrónimo**          | Acrónimo corto que identifica una process app en BAW. Junto con el nombre del proceso (`model`) direcciona el arranque de una instancia ([API-04](architecture/portal-procesos-baw/apis/API-016-procesos.md#post-bpm-processes)).                                                                                                                |
| **Instancia de proceso**          | Una ejecución concreta de un BPD, con su propio estado, datos y tareas ([MD-03](architecture/portal-procesos-baw/models/MD-03-instancia-proceso.md)).                                                                                                                                                                                            |
| **LTPA**                          | _Lightweight Third-Party Authentication_. El mecanismo de cookie de sesión de BAW. La cookie LTPA es la credencial real de la sesión; la gestiona el navegador y viaja con `withCredentials: true` ([FL-01](architecture/portal-procesos-baw/flows/FL-01-autenticacion-ciclo-vida-sesion.md)).                                                   |
| **Outcome (decisión de negocio)** | Decisión que cierra una tarea humana y determina cómo continúa el proceso (p. ej. Aprobar, Rechazar). **No es un concepto de la API de BAW**: se modela como una variable de negocio del proceso que el portal envía al completar la tarea ([MD-07](architecture/portal-procesos-baw/models/MD-07-accion-tarea.md)). No confundir con `actions`. |
| **`actions` (de BAW)**            | Enum cerrado de _operaciones_ que el usuario puede ejecutar sobre una tarea —`claim`, `cancel_claim`, `complete`, `assign`, `view`…—. Sirve para habilitar o deshabilitar botones, **no** para descubrir decisiones de negocio ([MD-07](architecture/portal-procesos-baw/models/MD-07-accion-tarea.md)).                                         |
| **`data_object`**                 | Única estructura con que la API de BAW transporta datos de negocio: `{ name, data }`. No lleva tipo, etiqueta ni obligatoriedad, por lo que el portal debe inferir o configurar los metadatos del formulario ([MD-06](architecture/portal-procesos-baw/models/MD-06-campo-formulario-dinamico.md)).                                              |
| **PDW**                           | _Performance Data Warehouse_. El almacén de métricas históricas de BAW, separado del motor de procesos. Es el origen previsible de los indicadores de rendimiento, sin endpoint REST confirmado ([MD-08](architecture/portal-procesos-baw/models/MD-08-indicador-rendimiento-proceso.md)).                                                       |
| **Process app**                   | Unidad de despliegue de BAW que agrupa uno o varios procesos y sus artefactos.                                                                                                                                                                                                                                                                   |
| **Reclamar (claim)**              | Asignarse una tarea que está disponible para un equipo pero aún no tiene responsable. Es requisito para poder completarla ([API-07](architecture/portal-procesos-baw/apis/API-017-tareas.md#post-bpm-user-tasks-task-id-claim)).                                                                                                                 |
| **Snapshot**                      | Versión congelada de una process app en BAW. Determina qué versión del proceso se arranca.                                                                                                                                                                                                                                                       |
| **Estado de SLA**                 | Clasificación de una tarea o instancia en _a tiempo_, _en riesgo_ o _vencida_. BAW **no** lo expone como campo: el portal lo **deriva en el cliente** comparando el reloj actual contra `due_date` y `at_risk_time` de la tarea ([MD-04](architecture/portal-procesos-baw/models/MD-04-tarea.md)).                                               |
| **Tasa de renovación**            | Indicador mostrado por el portal actual de BAW en «Rendimiento del proceso». **Sin definición confirmada**: no hay fórmula, ventana temporal ni denominador especificados ([MD-08](architecture/portal-procesos-baw/models/MD-08-indicador-rendimiento-proceso.md)).                                                                             |
