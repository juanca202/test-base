# MD-02: Proceso iniciable

Proceso que el usuario puede arrancar (FR-001). **Estado de validación: Confirmado** — contrato verificado con ejecución real contra `GET /rest/bpm/wle/v1/exposed/process` el 2026-09-15 ([API-03](../apis/API-016-procesos.md#get-rest-bpm-wle-exposed-process)), incluido el arranque real de una instancia con los identificadores que devuelve ([API-14](../apis/API-016-procesos.md#post-rest-bpm-wle-process)).

| Campo                     | Tipo    | Requerido | Descripción                                                      | Validaciones / restricciones                                                                                                                                                                                            |
| ------------------------- | ------- | --------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| bpdId                     | string  | **Sí**    | Identificador del proceso/BPD (`itemID` en la respuesta)         | Parámetro `bpdId` **obligatorio** de [API-14](../apis/API-016-procesos.md#post-rest-bpm-wle-process)                                                                                                                    |
| processAppId              | string  | **Sí**    | Identificador de la process app que lo contiene (`processAppID`) | Parámetro `processAppId` **obligatorio** de [API-14](../apis/API-016-procesos.md#post-rest-bpm-wle-process)                                                                                                             |
| processAppName            | string  | Sí        | Nombre de la process app                                         | —                                                                                                                                                                                                                       |
| processAppAcronym         | string  | Sí        | Acrónimo de la process app                                       | —                                                                                                                                                                                                                       |
| display                   | string  | Sí        | Nombre visible del proceso en la tarjeta                         | Confirmado en vivo: coincide exactamente con `processTemplateName` de la instancia creada por [API-14](../apis/API-016-procesos.md#post-rest-bpm-wle-process)                                                           |
| itemDescription           | string  | No        | Descripción breve                                                | Requiere `includeDescription=true` en [API-03](../apis/API-016-procesos.md#get-rest-bpm-wle-exposed-process); vacía (`""`) en los procesos de prueba de este ambiente — sin dato real que confirme su contenido poblado |
| snapshotID / snapshotName | string  | No        | Snapshot del proceso                                             | `snapshotName` puede venir `null` (snapshot por defecto)                                                                                                                                                                |
| branchID / branchName     | string  | No        | Rama de la process app                                           | —                                                                                                                                                                                                                       |
| startURL                  | string  | No        | URL ya resuelta para arrancar la instancia                       | `/rest/bpm/wle/v1/process?action=start&bpdId=...&processAppId=...` — usarla directamente en vez de recomponerla                                                                                                         |
| isMobileReady             | boolean | No        | Si tiene variante optimizada para móvil                          | Sin uso confirmado en el portal                                                                                                                                                                                         |

**Relaciones:** Proceso iniciable 1—N Instancia de proceso ([MD-03](MD-03-instancia-proceso.md)).

> **Historial de la laguna (resuelta el 2026-09-15).** La familia `/bpm/` (Process REST Interface) sigue **confirmada sin** ningún endpoint para descubrir los procesos arrancables — `POST /bpm/processes` ([API-04](../apis/API-016-procesos.md#post-bpm-processes)) permite arrancar un proceso si ya se conocen `model`/`container`, pero no permite descubrirlos, y solo autoriza a «los miembros de los equipos asignados a la opción _Expose to start_ del proceso». La familia WLE clásica sí tiene superficie real: `GET /rest/bpm/wle/v1/exposed/process` devuelve el catálogo completo con sus identificadores de arranque ya resueltos (`bpdId`, `processAppId`, `startURL`), verificado con lecturas y con una llamada de escritura real que arrancó una instancia de prueba (`Vacation request:303`). Detalle completo de la investigación: [RS-002 — Procesos iniciables vía WLE](../../../specs/archived/research/RS-002-procesos-iniciables-wle/README.md).
>
> **Pendiente, no bloqueante:** no se validó con un segundo usuario si el catálogo respeta estrictamente la autorización "Expose to start" por equipo (evidencia indirecta a favor: el nombre del recurso y el parámetro `forUser`, que valida usuarios reales, pero sin prueba diferencial).
