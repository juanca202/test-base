# MD-03: Instancia de proceso

Una ejecución concreta de un modelo de proceso (FR-006). **Estado de validación: Confirmado** (OpenAPI `process`; ejecución real 2026-09-16).

| Campo                     | Tipo               | Requerido | Descripción                          | Validaciones / restricciones                                                                                                                                                                                               |
| ------------------------- | ------------------ | --------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id                        | string             | **Sí**    | Identificador de la instancia        | —                                                                                                                                                                                                                          |
| model                     | string             | **Sí**    | Nombre del modelo de proceso         | Agrupador de [MD-08](MD-08-indicador-rendimiento-proceso.md)                                                                                                                                                               |
| container                 | string             | **Sí**    | Acrónimo de la process app           | —                                                                                                                                                                                                                          |
| container_name            | string             | **Sí**    | Nombre de la process app             | —                                                                                                                                                                                                                          |
| state                     | enum               | **Sí**    | Estado de la instancia               | `running` \| `finished` \| `terminated` \| `suspended` \| `stopped` \| `did_not_start`                                                                                                                                     |
| creation_time             | string (date-time) | **Sí**    | Fecha de creación                    | Columna «fecha de creación»                                                                                                                                                                                                |
| due_date                  | string (date-time) | No        | Vencimiento de la instancia          | Origen del estado de SLA **cuando está presente**. **Puede faltar:** el 2026-09-16 estuvo ausente en `PerformanceMonitoringProcess` (`id` `2072.92`) y presente en instancias de negocio (`Proceso de Créditos:205`, etc.) |
| name                      | string             | No        | Nombre de la instancia               | —                                                                                                                                                                                                                          |
| version                   | string             | No        | Acrónimo del snapshot                | —                                                                                                                                                                                                                          |
| version_name              | string             | No        | Nombre del snapshot                  | —                                                                                                                                                                                                                          |
| branch_name               | string             | No        | Rama de la process app               | —                                                                                                                                                                                                                          |
| modification_time         | string (date-time) | No        | Última modificación                  | —                                                                                                                                                                                                                          |
| input / output / internal | `data_object[]`    | No        | Variables de la instancia            | Solo con `optional_parts=data`                                                                                                                                                                                             |
| actions                   | enum[]             | No        | Acciones disponibles para el usuario | Solo con `optional_parts=actions`. Valores: `terminate`, `suspend`, `resume`, `comment`, `update_due_date`, `delete`, `add_document`, `update_document`, `delete_document`, `retry_steps`, `view`, `set_data`              |

**Campos derivados en el cliente** (no vienen de BAW): `isActive` = `state === 'running'` (filtro Activo/Completado de FR-006, donde Completado = `finished`); `slaStatus` según la regla de [MD-04](MD-04-tarea.md) aplicada a `due_date` **si está presente**.

**Relaciones:** Instancia 1—N Tarea ([MD-04](MD-04-tarea.md)); Instancia N—1 Proceso iniciable ([MD-02](MD-02-proceso-iniciable.md)).

> **No hay campo de equipo responsable.** El wireframe de «Procesos» muestra una columna «grupo responsable» que **este modelo no puede alimentar**: el equipo solo existe a nivel de tarea ([MD-04](MD-04-tarea.md)). Habría que derivarlo de las tareas de la instancia (N+1 llamadas) o retirar la columna.
>
> El enum `actions` incluye `comment`, pero **no hay ninguna ruta REST para comentar** — ver [API-08](../apis/API-017-tareas.md#post-bpm-user-tasks-task-id-complete).
